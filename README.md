# Own UI

Модульная Luau GUI-библиотека для Roblox.

## Структура

- `src/Loader.luau` — точка входа и загрузчик модулей
- `src/Window.luau` — создание окна
- `src/Tab.luau` — вкладки
- `src/Components/Button.luau` — кнопки
- `src/Components/Toggle.luau` — переключатели
- `src/Components/Label.luau` — текстовые элементы
- `src/Services/Theme.luau` — тема
- `src/Services/Animation.luau` — анимации
- `src/Utils/Signal.luau` — простые события

Проект рассчитан на обычные Roblox GUI-интерфейсы и не содержит игрового эксплойт-кода.
