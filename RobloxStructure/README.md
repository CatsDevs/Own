# Roblox DataModel Structure

Reference folder structure for Roblox Studio / Roblox DataModel.

This is a filesystem representation for reference and scripting projects. Roblox Studio's live DataModel also contains dynamic instances and service-specific objects that are created at runtime.

## Main services

- Workspace
- Players
- Lighting
- ReplicatedFirst
- ReplicatedStorage
- ServerScriptService
- ServerStorage
- StarterGui
- StarterPack
- StarterPlayer
- SoundService
- TextChatService
- Teams
- Chat
- LocalizationService
- MaterialService
- CollectionService
- HttpService
- MarketplaceService
- RunService
- UserInputService
- TweenService
- Debris
- TeleportService
- DataStoreService

See `DataModel.txt` for the complete reference tree included in this repository.
